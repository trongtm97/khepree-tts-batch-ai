Cài đặt Edge TTS

Engine online · cần mạng · MP3 · chỉ áp dụng tab Edge TTS

Giọng & tham số mặc định

Yêu cầu kỹ thuật

  • Cần internet khi chạy batch Edge.
  • Python worker: edge-tts, pydub — cài qua pip install -r python/requirements.txt.
  • Ghép MP3 cần ffmpeg trong PATH.
  • Luồng batch (song song): cấu hình tại tab .

Mã nguồn: github.com/rany2/edge-tts

Hướng dẫn sử dụng

Quy trình batch, cột bảng dữ liệu và import Excel

Quy trình nhanh

  1. Chọn tab phù hợp máy: VieNeu Turbo (CPU mạnh, 48 kHz), VieNeu Nano (máy yếu, 24 kHz), hoặc Edge TTS (cần mạng).
  2. Import dữ liệu: thư mục TXT, file Excel, hoặc thêm dòng thủ công. Text dài tự tách thành nhiều tác vụ (Cài đặt VieNeu).
  3. Chọn giọng và chỉnh tốc độ trên thanh cấu hình (ghi đè mặc định trong Cài đặt).
  4. Chọn thư mục xuất ở footer hoặc trong Cài đặt VieNeu.
  5. Bấm Bắt đầu batch — theo dõi Console phía dưới bảng.
  6. Luồng batch — số tác vụ chạy song song (Cài đặt VieNeu, mặc định 2).

Import Excel

Sheet đầu tiên, mỗi dòng = một tác vụ. Cột được nhận diện (tiếng Việt hoặc tiếng Anh):

  • Nội dung văn bản — bắt buộc (Text, Prompt…)
  • Tên file — tùy chọn (Name Save)
  • Nhóm — tùy chọn (Group)

Dùng nút Lưu file Excel mẫu ở góc trên để tải template chuẩn.

Import khác

  • Import thư mục — quét file .txt (thư mục con → cột Nhóm).
  • Import TXT — một hoặc nhiều file text.
  • Xuất JSON — sao lưu danh sách tác vụ.
  • Tách đoạn tự động — văn bản dài được chia khi nhập, dán hoặc import (~1200 ký tự/đoạn, chỉnh trong Cài đặt VieNeu).

Hai engine khác nhau

  • VieNeu Turbo — offline 48 kHz, chất lượng cao, CPU mạnh →
  • VieNeu Nano — offline 24 kHz, nhanh hơn trên máy yếu (chất lượng thấp hơn, nhất là tiếng Anh)
  • Edge TTS — online, cần mạng, MP3 →

Mỗi tab có danh sách tác vụ riêng. Bảng hiển thị toàn bộ tác vụ (cuộn trong vùng bảng), không phân trang.
